# OpenHina

**A Longitudinal Dataset of Japanese Voice Actress Social Media Activities (2022–2026)**

OpenHina 是个人制作的非官方、非商业粉丝归档。当前发布版收录截至 **2026 年 11 月 21 日**的公开 X 帖文索引，包含 868 张图片和 300 个视频或动图的链接与人工分类结果。

## 下载与使用

请从本仓库的 [Releases](https://github.com/wjx11111-11/OpenHina/releases) 下载 `OpenHina-online.zip`，解压后双击 `OpenHina-online/index.html`。

这是**在线媒体版**：图片、视频和视频封面从 X 的媒体服务器实时获取。使用时需要互联网连接，访问 X 媒体服务器可能需要网络加速服务。页面支持按发布时间、媒体类型、人工分类和推文文字筛选，并可查看推文详情与原帖链接。媒体链接可能随 X 服务变化而失效。

发布包只含浏览所需的推文 ID、文字、时间戳、分类及媒体链接，不含 twitterapi.io 原始 JSON、JSONL、归档数据库或本地媒体文件。GitHub Pages 暂未启用；请下载 ZIP 后在本地打开页面。
